# Repository Rules

Hard constraints for anyone (human or AI assistant) contributing to this repo.

## 1. Commit attribution

- Every commit is authored **only** by the repository owner:
  `Myles Vilceus <mylesv26@gmail.com>`.
- Do **not** add any AI attribution to commits or pull requests. This includes,
  but is not limited to:
  - `Co-Authored-By: Claude <...>` (or any other assistant) trailers
  - "🤖 Generated with Claude Code" or similar lines in commit messages or PR bodies
- Claude Code may write code, but the human owns the commit.

## 2. Committing and pushing

- Only create commits or push when the owner explicitly asks.
- Never force-push shared branches.

## 3. Secrets

- No credentials, API keys, or `.env` files in version control.
